# Movie Recommendation System

This project is a Movie Recommendation System built using Machine Learning and Python. 
It recommends movies based on content similarity using movie metadata such as genres, keywords, cast, and crew.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

## Dataset
The project uses the TMDB 5000 movies dataset including:
- tmdb_5000_movies.csv
- tmdb_5000_credits.csv

## Features
- Content-based movie recommendation
- Data preprocessing using Pandas
- Similarity calculation using machine learning techniques

## How to Run
1. Open the notebook in Google Colab or Jupyter Notebook
2. Run all cells
3. Enter a movie name to get recommendations
